## 这一版是什么

出生给你 30000 天寿命，这就是你唯一的货币。
买一段感情、一次旅行、一项技能，全部明码标价。
**15 分钟真实倒计时**里过完一生，结算时你的"人生账单"会告诉你——
你的钱（命）花在了哪里，值不值。

**零运行时依赖**：纯 ES Modules 手写，纯 Canvas 渲染，无框架、无构建步骤。
`npm install` 只装 Vite 一个开发服务器。

- 🧠 **8 大人生分类 × 160 件商品**：认知 / 体验 / 事业 / 家庭 / 社交 / 健康 / 娱乐 / 消费，普通 → 传奇 4 档稀有度，逐步解锁

## 设计原则（写进代码，不是写进 README）

**1. AI 永远只是锦上添花 —— 游戏先能离线玩通。**

无 Key、零联网，墓志铭由本地 4 层评语引擎生成，这就是离线默认体验。
接入 BYOK 后：AI 为每个岔路口的选择凝练人生信条、把际遇旁白按这局人生重新讲述、
在摸鱼时补一句扎心吐槽、在投胎时送来一句前世回响。

**所有这些都有本地兜底，AI 失败 / 超时 / 格式错 → 静默降级，游戏永不因 AI 卡死。**

**2. 四条承诺**

1. Key 只存在你浏览器的 localStorage，没有中间服务器，没有任何遥测上报
2. 请求直接从你的浏览器发到你的模型服务商，本仓库不代理任何流量
3. 失败静默降级——超时 25 秒、HTTP 报错、无配置，自动回到本地评语引擎
4. 额度由你设上限，用完不静默、不催促，选择权在你

**3. 开源版一行广告代码都没有。**

续命改为每日免费一次，锦囊刷新改为本局免费一次。
冒烟测试里有一条专门的断言扫描全项目，出现任何 `createRewardedVideoAd` 字样直接报错。

**4. 一套代码，两个平台。**

同一套纯 Canvas 游戏代码，通过一个 `platform-web.js` 适配层分别运行在
抖音小游戏（官方 `tt.*` API）与浏览器（tt-shim）。
平台调用全部设计了缺失兜底——在浏览器里自动降级为离线模式。

## 快速开始

需要 Node.js 18+。

```bash
# 方式一：下载本 Release 的源码压缩包后解压，进入目录
npm install
npm run dev
# 终端会打印一行地址（通常是 http://localhost:5173），复制进浏览器即可开玩
```

```bash
# 方式二：手动克隆仓库并切到本版本
git clone https://github.com/TThoney512/time-buyer.git
cd time-buyer
git checkout v0.4.0
npm install && npm run dev
```

游戏本身**零依赖**，也可用任意静态文件服务器直接托管：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

### 关于存档

跨局数据（成就、轮回积分、人生清单、语言、BYOK 配置）存在浏览器 **localStorage**，不会丢。
**进行中的一局不存盘**——关掉页面这 15 分钟的一生就结束了。这是有意为之。

## 已知限制

- **游戏内容（160 件商品、随机事件、Buff、墓志铭模板）目前是中文**。壳层已双语，
  但内容约 800 条、含大量中文互联网梗，直译会杀死笑点——这部分规划为社区贡献的本地化包。
- 进行中的一局不存盘（设计如此）。
- 浏览器直连 OpenAI 官方端点可能被 CORS 拦截，建议用 DeepSeek / Ollama 或反向代理。
